# valetskaya-site

Портфолио продуктового дизайнера Валентины Валецкой. Статический сайт без сборки: публикуется папка репозитория целиком (корень).

- `index.html` — отправляет на `web.html` (экран ≥ 700 px) или `mobile.html`, адрес кейса (`#case-…`) сохраняется.
- Web и Mobile — разные подачи, не адаптив одного в другой: свои HTML, CSS (`css/web.css`, `css/mobile.css`) и JS.
- `css/tokens.css` — токены из переменных Figma (коллекция «Портфолио»).
- Источник правды по дизайну — Figma «Портфолио — чистовик»: страницы «🖥 Web · UI-kit» и «📱 Mobile · UI-kit».
  Мобилка собрана по Frame 91 (117:130909). Решения Web от 22.11 вечером — см. бэклог в проекте.
- `about-lab.html` — песочница вариантов «Обо мне» (noindex), посетителям не показывается из меню.

## Публикация
- **GitHub Pages:** ветка `main`, папка `/ (root)`. `.nojekyll` отключает Jekyll. Публикуется сам после каждого пуша.
- **Netlify (по желанию):** Add new site → Deploy manually → перетащить папку репозитория целиком (без `.git`), или подключить репозиторий: Build command — пусто, Publish directory — `.`.
- Проверка перед публикацией: открыть `web.html` и `mobile.html`, открыть все три кейса, обновить страницу на адресе `#case-stat`, нет 404 в консоли.

## Визуальные правила (обязательны для всех правок)
1. Один главный визуальный акцент в видимой области (экран ≈ 1440×900 / 390×844): лайм-заголовок ИЛИ объект-декор ИЛИ яркая карточка — не всё сразу.
2. Ограниченный набор повторяющихся декоративных приёмов: стекло (одна плотность для кейсов), волосяная белая линия, лайм как акцент (только на тёмном), RT Obligat капсом, лёгкий наклон у карточек «Обо мне» и тултипа. Новый приём — только вместо существующего.
3. Отступы: между экранами 120, между группами внутри экрана 64, между карточками в ряду 24 (`--gap-screen`, `--gap-group`, `--gap-grid`).
4. Без грязных теней, обводок-наклеек и мутных градиентов. Контраст текста проверять всегда.
