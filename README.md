# valetskaya-site

Портфолио продуктового дизайнера Валентины Валецкой. Статический сайт без сборки.

- `index.html` — отправляет на `web.html` (экран ≥ 700 px) или `mobile.html`.
- Web и Mobile — разные подачи, не адаптив одного в другой.
- `css/tokens.css` — токены из переменных Figma (коллекция «Портфолио»).
- Источник правды по дизайну — UI-kit в Figma (файл «Портфолио — чистовик»).
- Публикация: GitHub Pages из ветки `main`, папка `/ (root)`. `.nojekyll` отключает обработку Jekyll.
